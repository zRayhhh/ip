# Ayre

This is a greenfield Java project based on the _Duke_ template.

## Getting started

The easiest way to use Ayre is to download the [latest release](https://github.com/zRayhhh/ip/releases/tag/v0.2-beta). Copy `Ayre.jar` into any folder you would like to run it in and double-click it, or navigate to the folder in a terminal and run `java -jar "Ayre.jar"`.
